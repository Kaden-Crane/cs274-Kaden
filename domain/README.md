# Phase 1 — Domain
Misson Statement
  The database tracks baseball card customer orders and the products associated with each order for online businesses.
Mission Objectives
- Retrieve a list of all orders by a given customers
- Track which products are included each order and in what quantity
- Record data and total amount of each order
- Retrieve all orders placed within a specific date range
- Identify top 10 best-selling products by quantity ordered
- Track current inventory level of each product
- Record the name, address, and contact information for each customers
Domain Description
- Online business would use this domain. It will maintain a detailed list of data for customer orders. It would help online businesses track what customers buy from them and all of the products included in the orders.
