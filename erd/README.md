## What does each table represent?
- Each table represents the transaction that is being made by a customer who places an order for boxes of baseball packs identifying what brand, series, and year that they are. It also tracks the price of what the customer pays.
## Why is it the type you labeled?
- If the tables were modeled differently there would be more many to many problems I would run into because the orders may have the same box and there wouldn't be a difference to identify  
## Which relationship was hardest to figure out?
- The hardest relationship to figure out was the box because I wasn't too sure how to connect it to the orders if there was many orders that had the same box so I settled for making a tible just to identify what is in each order.
## What changed? 
- I added in a payment table and a orderitem table to differentiate the product and the price instead of putting them both in one table.
